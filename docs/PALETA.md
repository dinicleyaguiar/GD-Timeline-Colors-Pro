# Paleta definitiva

O GD Timeline Colors Pro usa 16 slots fixos. A ordem é parte do contrato do plugin e deve permanecer estável entre versões.

| Índice | Categoria | Cor |
| ---: | --- | --- |
| 0 | Vídeo principal | `#2563EB` |
| 1 | B-roll | `#14B8A6` |
| 2 | Foto / imagem | `#EAB308` |
| 3 | Texto / Graphic | `#8B5CF6` |
| 4 | Motion / MOGRT | `#EC4899` |
| 5 | Áudio / voz | `#22C55E` |
| 6 | Música | `#6366F1` |
| 7 | FX visual | `#F97316` |
| 8 | Ajuste / cor | `#06B6D4` |
| 9 | SFX | `#EF4444` |
| 10 | Logo / branding | `#84CC16` |
| 11 | Nest / sequência | `#4F46E5` |
| 12 | Revisar | `#F43F5E` |
| 13 | Aprovado | `#16A34A` |
| 14 | Offline / problema | `#991B1B` |
| 15 | Organização / Bin | `#64748B` |

## Prioridade semântica

A classificação automática prioriza o significado editorial do item. Adjustment Layer, MOGRT/Motion e FX aplicado têm prioridade sobre a classificação genérica por extensão ou trilha.

O preset oficial é `preset/GD-Padrao-Definitivo.prlabelpreset`.
